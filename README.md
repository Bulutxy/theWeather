# Weather App

This project is a web-based weather application developed using HTML, CSS, and JavaScript. It retrieves real-time weather data from an API and displays it to the user.

## Features

* Search weather by city name
* Displays current temperature, humidity, and weather condition
* Fetches real-time data from an external API
* Simple and responsive user interface

## Technologies

* HTML
* CSS
* JavaScript
* REST API

## Installation

1. Clone the repository:
   git clone https://github.com/Bulutxy/theWeather

2. Open index.html in your browser

## Configuration

You may need to add your own API key in the JavaScript file.

## Usage

Enter a city name in the search box and view the current weather information.
